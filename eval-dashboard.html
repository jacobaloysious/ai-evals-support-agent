Measurement notes

Quality is the pass rate from the existing deterministic rubric. Model requests are LLM API calls made during each agent run. Tool calls are measured separately. Latency is end-to-end time for one scenario. Cost is estimated from the checked-in pricing rates and reported token usage; it is not an invoice total. Missing token data is shown as unavailable. One pass is directional evidence; repeat runs are needed because model outputs and provider latency vary.

Pricing sources: OpenAI and Meta.
